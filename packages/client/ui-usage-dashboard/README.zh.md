# @deepseek-ai/dsh-client-ui-usage-dashboard

[English](README.md) | 中文

模型消耗仪表盘，浏览器半端：设置外壳内的一个分区，将宿主 `usageDashboard/summarize` Remote 渲染为四张手写 SVG 图表——12 周调用强度日历热力图、头部模型在五个归一化用量维度（调用、输入、输出、缓存读、缓存写）上的雷达星图、30 天总 token 趋势折线图，以及带图例的按模型占比环形图。样式只使用主题 token，因此图表会随强调色与深色模式自动变化。

该分区注册到 `settings.section`（id `usage`，order 10，位于「插件」分区之前），带刷新按钮与加载、失败、空状态。控制器拥有加载生命周期：挂载即首次读取，读取进行中拒绝再次刷新，失败的读取会标记分区直到下次刷新。所有图形形状都是对汇总的纯投影，渲染器只是无脑的 SVG 画笔。

## Model Experience

无，此浏览器端设置界面只渲染只读汇总，不注册任何提示词、工具、消息或提供方请求。

#### KV Cache effect

无；本包从不组装模型输入。

## Known Limitations and Deferred Work

- **UTC 分桶坐标轴** —— 热力图与趋势读取宿主的 UTC 日分桶，远离 UTC 的部署会看到日历偏移；本地时坐标轴属于客户端，暂缓实现。
- **四种系列颜色** —— 雷达与环形图只保留头部四个模型；更多模型会被省略，而不是用循环颜色重复。
- **固定 30 天趋势** —— 趋势窗口固定；范围选择器暂缓实现。
