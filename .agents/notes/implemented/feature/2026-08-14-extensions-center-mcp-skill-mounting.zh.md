# Agent Note：扩展中心——设置驱动的 MCP 与技能挂载

Status: implemented

[English](2026-08-14-extensions-center-mcp-skill-mounting.md) | 中文

## 问题

MCP 服务器与技能此前只能在组合层配置：添加一个意味着要编辑 `cordis.yml`（或 preset），运行 Web GUI 的人没有任何在运行时挂载 MCP 服务器或技能的界面。因此所要求的「MCP 与 skill 插入式系统」没有产品入口——每条挂载路径都是一次配置文件编辑。

## 决策

新增双半端包 `@deepseek-ai/dsh-extensions-center`，它拥有一个持久设置命名空间（`extensions-center`，`live` 生效时机），其分节是经过 schema 校验的 MCP 服务器条目与技能条目列表，并在每次提交变更后据此重新同步运行时。

Node 半端通过标准 `installSettingsSection` 接缝注册命名空间（组合层 base 为空，因此分节在用户添加条目之前解析为 schema 默认值），并维护两个再同步器：`ServerMountManager` 将每个启用的服务器条目通过 `ctx.plugin` 挂载为独立的 mcp-client fiber，把条目的传输字段映射为 mcp-client 配置，并在条目被停用、移除或连接相关字段变更（配置指纹比较）时释放 fiber；失败的挂载会被记录、丢弃并在下一次设置变更时重试，且 `failOnStartupError` 默认关闭，因此一个坏条目不会拖垮应用。`SkillWriter` 将每个启用的技能条目渲染为配置的技能根目录下的 `<name>/SKILL.md`（默认为 `$DSH_HOME/skills`，即每个默认 skill-filesystem 提供方已扫描并监听的用户根目录），因此写入无需重新配置即可让每个会话的目录失效；被停用或移除的条目会删除其目录，扩展中心从不改动它不拥有的文件。命名空间上的 `validate` 钩子会拒绝它无法执行的配置段——重复的 id 或技能名、超出 mcp-client 命名空间预算的 id、所选传输方式用不到的字段、非法技能名、空技能正文。

浏览器半端向「插件」设置分区的 `settings.plugins.tab` 槽位贡献一个 `extensions` 标签页（order 20，位于随附的配置标签页之后）。页面通过设置作用域读取同一命名空间，渲染两组内容（MCP 服务器、技能），带逐条目的开关、编辑与移除，外加收起的添加表单；条目以整份草稿编辑，每次操作重算整个数组并以一次路径写入写回，宿主回读是唯一权威——未落地的写入会让视图保持诚实并标记保存失败（与插件卡片的 CardForm 相同的回读契约，应用于数组型条目）。控制器维护最近一次被接受分节的本地缓存，使快速连续的操作无论线路延迟如何都能正确组合，缓存仅由快照发布与写入回读刷新。

Web 组合把 Node 半端挂为宿主行（`extensions-center`），把浏览器半端放入 `dsh.client` 花名册；该包通过拆分的 `tsconfig.host.json`/`tsconfig.client.json` 工程（Node 与浏览器半端各自编译在自己的程序里）被两个类型检查聚合引用，标签页编辑的设置界面由宿主半端注册。

## 备选方案

- **保存时生成每服务器 `cordis.yml` 行**——从设置分节写组合文件。否决：它在用户背后修改部署配置，需要重新读取 loader，而设置接缝已提供带校验、修订围栏的持久状态与组合文件没有的活变更通知。
- **进程内注册条目的自定义技能提供方**——直接在 `ctx.skills` 上注册技能而非写文件。否决：技能注册表按作用域分层且 preset 拥有各自的提供方；写入被监听的用户根目录正好复用了既有发现与失效路径，并让条目对每个会话和重启都可见。
- **带热换配置的单个 mcp-client 实例**——改动单一连接而非逐条目挂载。否决：mcp-client 的契约是一个插件实例对应一个服务器、效果作用域内释放；逐条目 fiber 让每个服务器拥有自己的重连循环与命名空间，并免费获得释放语义。

## 影响

- MCP 服务器与技能现在是运行时数据：添加、编辑、启用或移除都是一次设置写入，持久化在用户的设置文件中，对每个会话即时生效。
- 技能条目以普通文件落入共享技能根目录，因此同名的手工创建目录会以文件系统提供方赋予的同一等级胜出；扩展中心的同步只移除它先前创建的目录。
- 编辑启用服务器的连接相关字段会释放并重新挂载该服务器，因此编辑活动条目时可见的代价是一次短暂的连接中断。
- 本包不随附任何内置扩展：分节在用户添加条目之前为空，默认部署保持不变。
- Web 包增加了一行宿主行与一行客户端行；两个半端均有单元测试覆盖（设置校验、挂载生命周期、技能渲染、控制器投影、标签页交互）。
